**有官方 API 文档的厂商（2 家）：**
1. **普渡科技 (Pudu Technology)**：官方开放平台 https://open.pudutech.com，有完整的云端 API 文档和 PUDU SKILL 工具。认证方式为 ApiAppKey + ApiAppSecret，支持 cn/sea/de/us 四个集群，覆盖 21 个功能组（状态查询、配送/运送/跑腿/顶升/巡航/呼叫任务、回充、地图、闪电匣、统计、广告、货柜、避险等）。
2. **猎户星空 (OrionStar)**：官方 OpenAPI 文档 https://openapi.orionstar.com/opendocs/zh/，认证方式为 Access Token（Bearer）+ IP 白名单。覆盖鉴权、企业信息、SSO、机器人信息/地图/控制指令（导航/取消导航/语音/TTS/工作模式/休眠/唤醒/重启/关机/充电）/任务（收盘/呼叫）/使用数据。

**无官方 API 文档的厂商（3 家）：**
3. **优地机器人 (Udi Robotics)**：官网 https://www.uditech.com.cn，未找到公开开发者门户或 API 文档。第三方报道提及有 API 接口但不公开。
4. **远鲸科技 (Marsmarch)**：官网 https://www.marsmarch.cn，2020 年成立的酒店机器人公司，无开发者门户。
5. **擎朗智能 (Keenon Robotics)**：官网 https://www.keenon.com，全球出货量第一的商用服务机器人企业，但无公开 API 文档。有与通力电梯的私有 API 集成报道。

## 任务：酒店设备市场覆盖率调研

- 用户需求：分析已对接设备（机器人4家+洗涤设备4家）在酒店市场的覆盖率，识别重要未对接厂商，计算补充对接后的覆盖率
- 数据来源：IDC、Frost & Sullivan、奥维云网(AVC)、博研咨询、云迹招股书等

### 关键发现
- **机器人当前覆盖率≈30~38%**：最大缺口为擎朗智能（酒店场景14.2%，与云迹13.9%并列第一但未对接）
- **小天鹅已通过美的U净平台间接覆盖**：小天鹅商用洗衣机QR码含app.littleswan.com域名，接入U净平台(phoenix.ujing.online)，使用已有美的IoT V3 API即可查询设备状态
- **洗涤设备覆盖率从55~65%提升至68~78%**：小天鹅覆盖后高档酒店覆盖率从30%跃升至90%+
- **综合覆盖率从43~52%提升至49~58%**；补充擎朗后可达56~65%；补充全部建议厂商后可达68~77%
- **擎朗智能无公开API文档**：官网keenon.com无开发者门户，有私有云管理平台和IoT集成但不对外开放，建议联系global@keenon.com索取
- **洛必德28%份额数据存疑**：来自宣传性来源，与IDC全球出货排名矛盾

### 产出文件
- `酒店设备市场覆盖率调研报告.md`：完整调研报告（初版，洗涤4家）
- `酒店设备市场覆盖率调研报告.html`：交互式可视化网页版（ECharts），已更新为9家厂商（含小天鹅via U净），新增已对接厂商酒店客户覆盖展示模块
