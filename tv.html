04 · 设备控制

空调面板：网页端统一控制

HJ-X40-TS 温控面板走 2.4G Wi-Fi 接入，平台侧补了 Echo 服务（MAC 换 deviceid）、MQTT Broker 分发和固件 OTA； 网页后台就能统一控制开关、温度、风速、模式、定时，同时回读温度、湿度、PM2.5 与在线状态。

协议
HTTP + MQTT

HTTP 取 deviceid / Broker 信息，MQTT 收发指令，JSON 包带 opcode

控制项
开关 · 温度 · 风速 · 模式 · 定时

下发 PULLSWITCH / PULLSPEED / PULLMODE / PULLTIMEONOFF

状态回读
温度 · 湿度 · PM2.5

设备上报 PUSHSENSORDATA / PUSHAC，网页按房间聚合，离线用 will 标记

固件升级
OTA

HEAD 取固件长度 → GET 拉取，下发 PULLUPDATE

05 · AI 能力

语音助手：一句话，走完客房里的所有事

客人对着电视说一句，或用手机扫码绑定房间后按住说话——不用找遥控器、不用翻菜单。 两种入口汇到同一个 AI Agent 中枢，再分发到三类能力：问服务、控电视、管设备。 第三类的每一次「调用」，背后就是前面几屏的真实设备接口。

接入一 · 电视语音唤醒

电视端麦克风远场拾音 + 关键词唤醒，喊一句就进入对话，完全免遥控、免手机；老人小孩也不用学菜单。

接入二 · 小程序扫码互联

扫电视上的房间二维码自动绑定房间号，按住手机说话，识别更准、更私密；绑定信息本地留存，下次免重复扫码。

06 · AI 产品

MindRouter：把多家模型收成一个入口

用大模型本身不难，难的是稳定地用在团队里——每家一个账号、一套密钥、一张账单；密钥散在谁手里、 谁花了多少说不清；想让非技术同事也能用，还得另做界面和权限。 MindRouter 把这些收拢成一个地址、一把密钥、一套额度，重点是给普通用户用的「创作中心」。

01
统一入口

兼容主流接口规范的一个地址，背后可以接多家模型。业务代码只认这个地址，换模型、加供应商都不用改代码。

02
控制台

给管理员：模型目录、用户、密钥、可用范围、额度。谁能用哪些模型、每月花多少，都在这里配。

03
创作中心

给普通用户：登录就能对话、出图、生成视频，不用懂接口和参数；每次调用扣自己的额度，作品自动进作品库。

这是可以直接点的演示：切换顶部「对话 / 图片 / 视频 / 作品」，在输入框里打字、点「生成」，额度会跟着扣。

一个入口 多家模型 按人发密钥 · 单独预算 密钥层面 限制可用模型 对话 / 图片 / 视频 同一个工作台 作品自动归档 · 可回看下载 用量与花费 按人按模型可见
